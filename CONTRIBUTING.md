# Contributing

Thanks for helping! Bug reports and ideas are the most useful thing right now: use the
[issue forms](https://github.com/MonkeyMatt87/family-planner/issues/new/choose).

For code: it's FastAPI with SQLite and plain HTML/JS/CSS, with no build step (see Development in the
README). Keep pull requests small and say what you tested on (browser, phone, Proxmox).

Please never commit real family data, PINs, calendar links or tokens. `python -m app.demo` gives you a
made-up family to test with.
