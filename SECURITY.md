# Security

Family Planner holds a family's calendar, kids' names and schedules, and medicine notes, so security
reports are taken seriously.

**Please don't open a public issue.** Report privately through
[GitHub's security advisories](https://github.com/MonkeyMatt87/family-planner/security/advisories/new).
You'll get a reply within a few days, and a fixed release as soon as possible.

Only the latest release is supported. Update with the installer (see the README).
